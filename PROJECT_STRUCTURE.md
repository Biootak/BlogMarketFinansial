## Important Notes

### Go Installation Required

**The Go programming language is not currently installed on this system.** Before proceeding with development:

1. Install Go 1.21 or later following the instructions in `SETUP.md`
2. Verify installation: `go version`
3. Download dependencies: `go mod download`
4. Generate Ent code: `go generate ./ent`

### Environment Configuration

The `.env.go` file contains a template with the current project's credentials. To use it:

```bash
# Copy to .env (or use directly)
cp .env.go .env

# Update any values as needed
```

### Docker Development

For the easiest setup, use Docker:

```bash
# Start PostgreSQL and Redis
docker-compose -f docker-compose.go.yml up -d postgres redis

# Or start everything including the Go backend
docker-compose -f docker-compose.go.yml up -d
```

### Compatibility

The Go backend is designed to be **100% compatible** with the existing Next.js frontend:

- Same JWT tokens (uses AUTH_SECRET from NextAuth)
- Same API request/response formats
- Same database schema (Ent will match Prisma)
- Same error codes and messages
