بازنویسی سیستم آیکون

گزارش فعلی: آیکون‌ها «اصلاً درست نیستن». این یه prototype کامله از سیستم جدید — تو می‌تونی قبل از اعمال در کد، diff رو اینجا ببینی.

۱. تشخیص

بدون screenshot، چهار حالت محتمل برای خرابی فعلی — هر کدوم یه راه‌حل:

الفآیکون‌ها blank یا اصلاً رندر نمی‌شن — احتمالاً inline SVG سفارشی (bold/italic/underline) با stroke=1.25 بِر شده یا کرش می‌کنه.
بbuild artifacts stale، browser cache قدیمی لود می‌کنه — hard refresh یا rm -rf .next.
جmapping اشتباه — registry کلید kebab-case درست resolve نمی‌کنه، یا alias PascalCase هنوز call-siteهای قدیمی رو ساپورت می‌کنه ولی icon های فعلی alias قدیمی می‌گیرن.
دسایز/رنگ state در status-bar و bubble-menu — hierarchy بصری نامشخص، چشم نمی‌دونه اول کجا بره.

طرح v2 هر چهار حالت رو هم‌زمان fix می‌کنه — حتی اگه فقط یکیش دلیل خرابی باشه.

۴. Full toolbar — قبل / بعد

اگه scroll کنی، مقایسه می‌بینی: ردیف اول فعلی، ردیف دوم همون با اصلاحات.

● قبل — فعلی

↑ مشکل: font-family و font-size هردو Text، arrow در toolbar حس aggressive، indent در RTL معنای معکوس می‌ده.

● بعد — پیشنهاد

↑ بهتر: bold در حالت active (filled)، font-family/font-size متمایز (Type vs A↕a)، palette، corner-down برای indent، chevron ظریف‌تر.
