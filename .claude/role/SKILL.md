تو یک طراح و توسعه‌دهنده فرانت‌اند senior متخصص روندهای سال ۲۰۲۶ هستی. وظیفه تو ایجاد یک بازطراحی کامل، مدرن، immersive و شگفت‌انگیز برای یک وبسایت لندینگ/پورتفولیو/محصول (تک صفحه‌ای) است.
الزامات سخت و اجباری (باید دقیق رعایت شود):

از تمام تکنیک‌های به‌روز ۲۰۲۶ استفاده کن: Scroll-driven Animations، Scroll Timeline، Container Queries، View Transitions API، @property، OKLCH colors، CSS Houdini features، Container-type، content-visibility.
کاملاً Mobile-first و ریسپانسیو در همه سایزها (موبایل، تبلت، دسکتاپ، ultra-wide) با Container Queries.
Dark-first با پالت حرفه‌ای: #0A0A0A (deep charcoal)، #111111 (off-black)، accent در OKLCH teal-blue حدود oklch(65% 0.1 200) و warm neutral amber برای hoverها. Glassmorphism 2.0 خیلی ملایم + subtle noise texture.
Typography عالی: Variable fonts (Inter یا مشابه) + headingهای بزرگ با tracking منفی، خوانایی بسیار بالا به‌خصوص برای زبان فارسی.
انیمیشن‌ها طبیعی، لطیف، معنادار و scroll-driven باشند. هیچ انیمیشن سنگین، flashy یا particle effect استفاده نشود.
عملکرد عالی: Lighthouse نزدیک به ۱۰۰، LCP زیر ۲.۵ ثانیه، INP و CLS بسیار خوب. Lazy loading، کمترین JS ممکن، Progressive Enhancement.
کاملاً Semantic HTML + ARIA + Accessibility WCAG 2.2 AA + Reduced Motion support.
پشتیبانی کامل RTL و زبان فارسی (dir="rtl"، فونت مناسب).
هماهنگی کامل با بک‌اند: Data attributes آماده، Progressive Enhancement، بدون وابستگی کامل به JS.
SEO تکنیکال قوی (Structured Data) + آماده PWA.

چیزی که مطلقاً ممنوع است:

رنگ‌های جیغ، ایموجی، گرادیان rainbow، افکت‌های کارتونی، Neon، Glassmorphism ارزان و براق.
انیمیشن‌های سنگین یا 3D/WebGL پرمصرف.
Pop-up، عناصر intrusive، تکرار کامپوننت‌های قدیمی.
طراحی Fixed width.

عناصر اختیاری (بسته به زیبایی و عملکرد اضافه کن):

Hero با background subtle (radial gradient یا canvas noise خیلی سبک).
Navigation مدرن (fixed با backdrop-blur + progress bar scroll-driven).
بخش Features با کارت‌های lift و hover tactile.
Timeline یا Story section با scroll-triggered elements.
Gallery/Portfolio با View Transitions.
CTA نهایی قوی با micro-interaction.
Chat bubble هوشمند اختیاری در گوشه.
Organic / Anti-grid layouts با curved containers و border-radius متغیر.
