# بخش ۱۲ — بنچمارک با رقبای جهانی

همیشه محصول را با این‌ها مقایسه کن و بهترین رویکرد را اقتباس کن (نه کپی).

| محصول | از چه یاد بگیریم | چه نکنیم |
|-------|------------------|----------|
| Apple Wallet | اعتماد، سادگی لمسی، Passkey اولیه | پیچیدگی بی‌دلیل |
| Revolut | انبوه ویژگی در یک اپ، progressive disclosure | شلوغی بی‌سازمان |
| Wise | شفافیت کارمزد (structural honesty)، چندارزی | پنهان‌کاری هزینه |
| Nubank | تجربه موبایل‌محور در بازار نوظهور | غفلت از دسکتاپ ادمین |
| Mercury | مینیمالیسم حرفه‌ای، داشبورد کم‌چگالی | حذف اطلاعات حیاتی |
| Monzo | round-up، پیام‌رسانی دوستانه | شوخی در لحظه حساس مالی |
| Stripe | API درجه‌یک، دقت مستندات | رابط کاربر گنگ |
| Linear/Notion | سرعت کیبورد، طراحی آرام | افکت‌های بی‌دلیل |

## رقبای محلی (تحقیق لازم)
- HesabPay، M-Paisa، و کیف‌های موبایلی افغان — نقاط قوت/ضعف.
- بانک‌های محلی و کانال‌های پرداخت.
- ناظم: بانک مرکزی افغانستان (DAB) — الزامات KYC/AML.

## رویکرد برتر را اقتباس کن با واقعیت افغانستان
زبان (دری/پشتو)، کانال پرداخت محلی، ناظم، و زیبایی‌شناسی اختصاصی (Tier-3 personality).
