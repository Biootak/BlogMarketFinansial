# Blueprint — احراز هویت (KYC)

**نقش:** customer (اولین ورود)
**وظیفه اول:** «سریع و با اعتماد هویتم را تأیید کنم.»

## Flow (Progressive Disclosure)
```
۱) شماره + کد  ─▶ ۲) شناسه ملی  ─▶ ۳) عکس سلفی/مدرک  ─▶ ۴) بررسی
```

## اصول
- گام‌شمار واضح: «گام ۲ از ۳ — حدود ۳۰ ثانیه».
- اسکن دوربین‌محور (نه آپلود کند).
- رزومه بین دستگاه (اگر خروج کرد، ادامه از همان گام).
- microcopy آرام: «در حال تأیید امن اطلاعات…».

## امنیت
- شناسه ملی هش‌شده (هیچ ذخیره متنی).
- محدودیت نرخ در کد تأیید (rate limit).
- تطبیق چهره (اختیاری، پس از MVP).

## States
- Loading: پیشرفت گام.
- Error: «کد اشتباه است — ۳۰ ثانیه دیگر تلاش کنید».
- Reject: «مدرک رد شد — دلیل + بازتلاش».

## چک‌لیست AI-Slop
- [ ] گام‌شمار انسانی؟
- [ ] بار شناختی کم؟
- [ ] طراحی اختصاصی (نه فرم عمومی)؟
