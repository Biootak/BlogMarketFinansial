# Blueprint — کیف پول (Wallet Home)

**نقش:** customer (موبایل‌محور)
**وظیفه اول:** «موجودی‌ام چقدر است و آخرین تراکنش کجاست؟»

## Layout (موبایل)
```
┌─────────────────────────┐
│  سلام، [نام]      🔔 ⚙️  │  ← هدر سبک
├─────────────────────────┤
│  ┌─────────────────────┐ │
│  │ موجودی کل           │ │  ← کارت قهرمان
│  │ ١٢٬٥٠٠ ؁AFN        │ │  ← عدد tabular 3xl
│  │ [نمودار ریز ۷روز]   │ │
│  └─────────────────────┘ │
│  [انتقال] [دریافت] [قبض] │  ← دکمه‌های سریع
├─────────────────────────┤
│  آخرین تراکنش‌ها         │
│  ┌─────────────────────┐ │
│  │ ↗ ارسال به علی  -٥٠ │ │  ← TransactionRow
│  │ ✓ دریافت از مرضیه +٢٠٠│ │
│  └─────────────────────┘ │
└─────────────────────────┘
   [ + انتقال ]  ← FAB
```

## Layout (دسکتاپ/ادمین-نه)
- سایدبار چپ (۳۲۰px) با منو.
- ستون اصلی: کارت موجودی + نمودار + جدول تراکنش صفحه‌بندی‌شده.

## States
- Loading: skeleton کارت موجودی + خطوط تراکنش.
- Empty: «هنوز تراکنشی نداری — اولین انتقالت را انجام بده» + CTA.
- Error: پیام + تلاش دوباره.
- Offline: نشان «آفلاین — داده ذخیره‌شده».

## Tokenها
- کارت موجودی: `color-surface-raised`, radius ۱۲, shadow sm.
- عدد: `color-text` 3xl, tabular-nums.
- CTA ثانویه: `color-personality` (زعفران).

## چک‌لیست AI-Slop
- [ ] فرمت AFN صریح؟
- [ ] کارت گرد یکسان کلیشه‌ای نیست؟
- [ ] هویت اختصاصی دارد (نه لوگوی رقیب جابه‌جاپذیر)؟
