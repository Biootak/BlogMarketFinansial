# Blueprint — پنل مدیریت (Admin)

**نقش:** admin / support (high-density)
**وظیفه اول:** «وضعیت سیستم، تقلب و کاربران را در یک نگاه مدیریت کنم.»

## Layout (دسکتاپ)
```
┌──────────┬───────────────────────────────────┐
│ سایدبار  │  KPIها (بالا، خلاصه عددی)          │
│ ـــــــ  │  ┌────┐ ┌────┐ ┌────┐ ┌────┐     │
│ داشبورد │  │تراکنش│ │کاربر│ │حجم │ │شکایت│    │
│ کاربران  │  └────┘ └────┘ └────┘ └────┘     │
│ تقلب     ├───────────────────────────────────┤
│ تنظیمات  │  صف بررسی تقلب (جدول فشرده)       │
│          │  [فیلتر] [جزئیات] [تأیید/رد]     │
└──────────┴───────────────────────────────────┘
```

## بخش‌ها
- **KPI:** تراکنش امروز، کاربران فعال، حجم AFN، موارد باز.
- **صف تقلب:** لیست flagsخورده با امتیاز ریسک، اقدام تأیید/رد.
- **مدیریت نقش:** اختصاص دسترسی دانه‌ای.
- **Audit log:** جدول غیرقابل تغییر با فیلتر زمان/عمل.

## اصول
- الهام Mercury (مینیمال، چگال) نه شلوغی.
- جداول با header چسبان، ستون‌های قابل مرتب‌سازی.
- هیچ رنگ‌آمیزی بی‌دلیل؛ فقط semantic (خطر=red با آیکون).
